# wx-agent

把 AI 接到本机微信：读取指定聊天、原生发送文字/图片/语音，并按联系人或群聊规则持续自动回复。

这个仓库整理了 `wechat-native` skill 和它所依赖的 `WeChatLocalTool` 运行程序。Skill 是 AI 的操作入口；实际读写微信的是本地运行程序。只安装 Skill 不能接通微信。

> 当前交付为 **macOS Apple Silicon 的源码安装包**。历史验证基线是微信 **4.1.13 / 269602** 的授权测试副本；不包含微信客户端、账号数据或数据库密钥。全新机器还需完成测试副本和本机数据访问准备，不是双击即可接管任意微信版本的通用安装器。

## 链路

```mermaid
flowchart LR
    A[微信本机数据库变化] --> B[macOS 文件事件]
    B --> C[读取获授权会话的增量消息]
    C --> D[触发规则与静默窗口]
    D --> E[Codex CLI 生成回复草稿]
    E --> F[检查新消息、本人接管与暂停开关]
    F --> G[微信原生发送]
    G --> H[核对新增记录和服务器编号]
```

- **手动操作**：AI 经 `skills/wechat-native/scripts/control.py` 调用本地工具，精确查联系人、读取聊天、发送或复核回执。
- **自动回复**：一个本地后台服务管理已授权会话。每个会话最后一条入站消息后默认等待 10 秒，续发会重新计时，再调用 Codex 生成草稿。
- **群聊规则**：支持明确配置的全部消息、原生 @、关键词、语义条件及发送者筛选。
- **本人接管**：本人手动接话、新消息到达或暂停开关变化，会取消尚未发送的旧草稿。
- **未知发送结果**：保留原 request-id，只读复核，不自动换 ID 再发。

这条链路运行在 Mac 本机，不包含个人工作台的 Windows/WSL 助手服务，也不依赖截图点击微信界面。

## 安装与使用

完整步骤见 [安装说明](docs/INSTALL.md)。安装动作本身不配置联系人、不启动监听、不发送消息。

安装并完成本机验证后，在 AI 对话中使用 `wechat-native`：

- “读取与某人的最近聊天。”
- “给某人发：今天几点出发？”
- “监听某人，按我指定的语气自动回复。”
- “在某群里只有 @ 我时才回复。”
- “暂停微信自动回复。”

对象重名时先确定精确 ID；群聊需要明确触发条件。已有暂停状态不会因为读取 Skill 或安装源码而自动恢复。

## 能力与验证边界

- 历史本机实现已具备文字、图片、SILK 语音的原生发送及本地记录读取；本次分发验证见 [VALIDATION.md](docs/VALIDATION.md)。
- `sent` 表示核对到新增原生记录及非零服务器编号，不等于对方已读。
- 读取范围是微信已经同步到本机的数据；不提供云端未同步历史下载。
- 自动回复目前依据文字和可理解的混合消息批次，不含图片识别或语音转文字。
- 新微信版本需要适配检查；静态匹配通过、服务已启动、单元测试通过均不等于真实收发闭环已通过。
- 新设备的微信测试副本、系统正常授权、本地数据库访问条件和 Codex 登录需要自行准备。仓库没有包含历史私有状态。

## 打包原则

源码包包含 Skill、运行源码、适配特征、安装脚本与测试；不包含聊天记录、联系人配置、账号密钥、发送日志、个人队列、微信客户端或第三方 SDK 二进制。安装后生成的本机配置仅留在本机。
