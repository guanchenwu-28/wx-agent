# v0.1.0 — 微信 AI 接管源码安装包

首次将 `wechat-native` Skill 与 WeChatLocalTool 本地运行程序整理为独立仓库。

- 包含完整 Skill、原生微信收发/读取源码、事件自动回复、版本适配及源码安装工具。
- 去除个人联系人、硬编码用户目录和旧单人迁移入口；本机依赖由配置指定。
- 安装不自动开启监听，真实收发由用户明确指定联系人与内容或规则后执行。
- 提供源码安装 ZIP、单独 Skill ZIP 以及 SHA256 校验文件。

目标平台是 macOS Apple Silicon。历史适配基线为微信 4.1.13 / 269602。全新机器仍需自行准备测试副本、正常系统授权、本机数据库访问条件与 Codex 登录；包内不含微信客户端、第三方 SDK 二进制、聊天记录或密钥。

这是源码安装预发布，不宣称在全新设备上完成了一键安装及真实自动回复验收。详见仓库安装说明与验证记录。
