# 安装包

当前版本：**0.1.1**。

- [完整源码安装包](wx-agent-v0.1.1-macos-arm64-source.zip)：下载并解压，进入 `wx-agent` 后运行 `./install.sh`。
- [单独 Skill 包](wechat-native-v0.1.1-skill.zip)：只含 `wechat-native`，需要已经安装 runtime。
- [SHA256 校验](SHA256SUMS.txt)。

环境要求和首次配置统一见根目录 [INSTALL.md](../INSTALL.md)。GitHub 文件页面可点击 **Download raw file** 下载 ZIP；也可克隆整个仓库。

这里与对应 Release 保存相同文件。ZIP 不嵌套本目录；从 Git checkout 执行 `python3 scripts/package.py` 可重新生成。
